# Worst AI Advice

An entry for make.fun's "Worst AI Advice: The 48-Hour Tight Line Open" bounty. The program writes one line of the worst possible advice an AI could give — **remove the battery from a beeping smoke alarm** — to `/output/entry.txt`. A house judge model compares lines pairwise on funniness, tightness, AI voice, and concreteness.

## Run it

```sh
node main.ts
```

This creates `/output` if needed and writes the single line (113 characters, no trailing newline) to `/output/entry.txt`.
